Coreon · self-evolving foundation model · 진행 상황

스스로 성장하는 코딩 모델 —
그 성장이 진짜임을 측정으로 증명했다.

Rust와 Apache Pekko 위에 올린 자기개선(self-evolving) 파운데이션 모델 (Qwen2.5-Coder-7B 기반). 모델이 스스로 문제를 풀고 그 결과로 다시 학습하면 성적이 오릅니다. 핵심 질문 — 이게 진짜 실력인가, 아니면 외운 것인가? — 을 두 종류의 외부 벤치마크로 검증했고, 그 답과 인프라를 이 페이지 한 장에 정리합니다.

시험 1 · LiveCodeBench · “커닝 잡는 시험”

학습 끝난 뒤 새로 나온 문제에서도 올랐다 = 진짜 학습

문제를 출제 날짜로 나눠, 모델이 학습을 끝낸 시점(2024-09) 이후에 나온 문제만 채점합니다. 절대 본 적 없는 문제죠. 여기서 오르면 외운 게 아니라 일반화입니다. 측정은 여러 번 시도 평균(aggregate pass@1) 기준 — 자기개선의 이득이 사는 곳입니다.

시험 2 · BigCodeBench · “난이도 높은 시험”

numpy·pandas 쓰는 실무형 문제 — 여기선 우열이 좁혀졌다

강화학습만 안정적으로 상승 (14.6→18.1, +0.035 ≈ 2σ). 일반 자기개선은 거의 못 올림 (14.6→15.5, 자기 노이즈 안). 그리고 첫 시험에서 2배였던 강화학습의 우위가 여기선 소폭(+0.99σ)으로 축소 — “강화학습이 얼마나 더 좋은가”는 시험 종류에 따라 다르다.
방법론에서 얻은 것

측정에 대한 두 가지 교훈

metric

“채점 방식”을 잘못 고르면 결과가 거꾸로 보인다. 처음엔 “가장 확신하는 답 1개”(greedy)로 채점해 자기개선이 나빠 보였습니다. 이득은 여러 번 시도 평균에서 나타나며, 기준을 맞추자 드러났습니다 — 결과를 믿기 전에 측정 방식부터 검증.

sharpening

자기개선 = “뾰족해지기”. 정답 하나에 확신을 몰아줘 한 번에 맞힐 확률(pass@1)은 오르지만 여러 번 중 하나라도 맞힐 확률(pass@5)은 떨어집니다 — 다양성을 희생해 정확도를 얻음. 난이도 시험에서 가장 뚜렷하게 관측.

P5–9측정 규율. 앙상블·전문가(정직한 부정 결과); Shape-C 신뢰도 보정; 외부 Qwen 검증; 1-round LoRA 0.40→0.73.
P10–16논문 이식은 LoRA 스케일에서 실패. JEPA·DPO·Muon·OPD — DeepSeek-V4의 기법들이 조용한 substrate에서 모두 짐; 분산 바닥 지도화.
P17–20첫 알고리즘 승리. 멀티라운드 SFT + 추론 pass@k 포화 곡선; r=6에서 0.581, seed 기록 0.645 (base의 3배).
P21Pekko 네이티브 브릿지. Candle 네이티브 Qwen2 추론 + LoRA 학습 + REINFORCE, Python 사이드카 없이.
P22 §6.5외부 벤치마크 + 7B. 0.5B→7B 이관; LiveCodeBench(오염)·BigCodeBench(난이도) 양축에서 6-seed로 자기개선 전이 측정 — 이 페이지의 결과.
