  • Format seeds must match verifier contract (slot vs ); } suffix).
  • Default probe stops (\npub , \nfn , \nuse ) shred multi-line modules.
  • Unique _verify_* roots — shared dirs were raced by concurrent smokes.
  • Hard train after a small harvest collapses eval (v6b/v7); gentle 30 steps / 5e-5 kept r1 alive.
