root cause

One tooling bug drove most of the corrections. FilteredDomain never delegated truncate_completion, so every hard-tail experiment (all use --prompt-skip-list) ran with completion truncation off. That mis-measured the base (0.246 vs the true 0.422) and starved the RL reward (a 3× gap vs the evaluator), manufacturing both the “inverted-U” and the “RL collapse.” Fixed in ad86e22; everything above is re-scored on one consistent ruler.
